# knowledge/ — 紫微格局知识库（repository-local）

`divination/ziwei.js` 的格局匹配引擎从这里读取 `.md` 文件，逐篇解析出「主星条件 / 吉星加会 / 等级」，用于给命盘标注传统格局。

## 解析规则（代码侧 contract）

`ziwei.js` 的 `parsePatternFile()` 对每篇 md 做关键词提取：

| 提取项 | 命中方式 | 说明 |
|---|---|---|
| 主星 | 文中出现已知星曜名（紫微/天机/太阳/武曲/天同/廉贞/天府/贪狼/巨门/太阴/天相/天梁/七杀/破军/文昌/文曲/左辅/右弼/天魁/天钺/禄存/天马/擎羊/陀罗/火星/铃星/地空/地劫/解神/天喜/红鸾） | 命中即作为主星条件 |
| 吉星加会 | 出现「禄存」「化禄/化权/化科」「左右」「昌曲」「魁钺」 | 加入助星条件 |
| 格局等级 | `大富大贵/极美/极贵`→贵；`富贵/大富/大贵`→富；`凶/刑/破格`→凶；`平常/普通`→平 | 默认「平」 |

所以每篇格局文件只要**如实描述**即可被解析：写清主星搭配、加会条件、格局高低。

## 目录约定

- 文件名 = 格局名（如 `紫府同宫.md`）
- 一篇一格局，正文为中文，含「主星 / 加会 / 等级 / 说明」四段
- 不参与匹配的文件（总论、术语、命理交叉类）会被 `skipNames` 列表过滤 —— 新增总论类文档时请加到 `ziwei.js` 的 skipNames

## 现状

当前 6 篇为核心常见格局的**种子数据**（据通行紫微典籍整理，标注为「待校订」，接入评测/生产前请对照原书复核）。可扩展方向：

- 补齐 108 星系常见格局（约 30–50 篇）
- 接入青囊 `packages/knowledge`（你自己的 TS 规则库）后，可改为从那里生成 md

## 加载优先级（ziwei.js 已改）

1. 本目录 `knowledge/`（项目内，**优先**）
2. `process.env.KNOWLEDGE_DIR`
3. `process.env.OPENCLAW_KNOWLEDGE_DIR`
4. `~/.openclaw/workspace/knowledge`（旧路径，仅作兜底）

任何一层命中即用，全部不存在时格局匹配降级为 0 条（不影响排盘本体）。
